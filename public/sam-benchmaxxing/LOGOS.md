# sam-benchmaxxing logos (image sub-agent, 2026-10-29)

Clean single-colour marks for the graphics builders. Every file: one fill (#000000 on the root `<svg>`, so recolour
with `fill` / `currentColor` on the root or each child), all gradients, masks, classes and styles removed, viewBox
tight to the mark (measured with resvg innerBBox; within ~0.2 user units). The untouched Commons downloads are in
`assets-src/sam-benchmaxxing/logos_raw/`. Trademarks remain their owners'; the files are on Commons as
PD-textlogo / PD-shape (too simple for copyright) or CC0, as listed.
