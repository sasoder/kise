# Airline logo SVGs — scott-aircraft-order (Cheeky Pint S4E05, Scott Kirby)

Fetched 2026-10-22. All files open as real SVG with vector path/polygon data (no scripts) and were rasterised with
`qlmanage` onto a labelled contact sheet and checked by eye. All are registered trademarks of the airlines, whatever
the copyright status. Use them only to identify the airline.

Two kinds of source:
- **Commons**: Wikimedia Commons, the airline's real mark. Licence is what the Commons file page says
  (`LicenseShortName`). "Public domain" there means the PD-textlogo / simple-geometry rationale, with a trademark
  warning.
- **Simple Icons**: used only where Commons has no symbol-only file (United globe, Qantas kangaroo, Singapore
  Airlines bird, a standalone BA Speedmarque, the Emirates calligraphy alone). The SVG data is CC0 1.0
  (simple-icons project, https://github.com/simple-icons/simple-icons). The marks are single-colour silhouettes,
  filled by cdn.simpleicons.org with the project's brand hex (given below). Recolour freely; they are not the
  airline's multi-colour artwork.
